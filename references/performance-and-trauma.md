# Performance and Trauma

## 1. 表演链

重大刺激优先检查：

`外部刺激 → 第一本能 → 身体反应 → 再确认 → 理解 → 控制 / 失控 → 结果动作 → 动作后余波`

不是每拍都完整出现，但不能让重大信息“听到后一帧就完成全部情绪”。

## 2. 角色专属反应语法

禁止所有角色统一使用：

- 眼神一震
- 呼吸一滞
- 嘴唇微张
- 手指收紧
- 喉结滚动
- 身体僵住
- 眉头紧皱
- 泪光

这些动作可以用，但必须符合具体角色、具体刺激和当前景别。

每个主要角色至少建立：

- 害怕时会做什么
- 被羞辱时会做什么
- 想掩饰时会做什么
- 想控制别人时会做什么
- 真正动摇时会做什么
- 作出决定后身体会怎样变化

## 3. 创伤先进入身体

创伤优先通过：

- 出口扫描
- 对门锁、脚步、金属声的反应
- 下意识保护私人物品
- 对被触碰的延迟反应
- 肩背收缩
- 呼吸和吞咽
- 距离管理
- 坐位选择
- 门口停顿
- 睡眠和安全感行为

如果画面已经能表达，不用 VO 再解释一遍。

## 4. 创伤碎片

默认长度只是创作建议，不是硬规则：

- 0.3 至 0.8 秒：纯感官刺入
- 0.8 至 1.5 秒：动作或物件记忆
- 1.5 秒以上：需要观众理解明确过去信息时才扩展

触发必须明确：
当前钥匙声 → 过去锁舌声
当前手腕被抓 → 过去束缚触感
当前房门关上 → 过去铁门闭合

## 5. 压抑愤怒

压抑愤怒不是“面无表情”。

可见过程可以是：

1. 身体先准备退
2. 人物意识到自己又在退
3. 停下
4. 把注意力重新放到对手身上
5. 不解释
6. 选择一个实际动作

力量来自“新处理方式”，不是来自更大的表情。

## 6. 强动作后的余波

发生以下行为后，不应立刻无缝进入普通台词：

- 拥抱
- 亲吻
- 扇耳光
- 推人
- 挡拳
- 摔物
- 公开拒绝
- 公开站队
- 救人
- 重大秘密揭晓

至少检查：

- 谁先看谁
- 谁先撤
- 谁没有恢复
- 谁发现了对方的 Reaction
- 谁改变后续行动
- 谁开始重新评估关系

## 7. 无台词人物

无台词不等于静止。

允许：
- 呼吸变化
- 视线转移
- 重心变化
- 小幅退让
- 停止原本动作
- 重新拿稳物件
- 看向出口
- 观察别人反应

禁止无原因的“活人感动作”：
- 随机舔唇
- 随机整理头发
- 随机耸肩
- 每镜都眨眼和吞咽

## 8. 景别与可见性

全景：
读距离、站位、退让、让路、占据空间。

中景：
读身体动作、关系距离、接触准备。

近景：
读控制、理解、视线、微表情。

特写：
只留给对剧情真正有意义的细节或不可替代的情绪转折。

不要用极近特写代替关系调度。
